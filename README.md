*Grounded Multimodal AI for Few-Shot Industrial Anomaly Detection and Root-Cause Analysis*


This project aims to develop an AI-based industrial monitoring system that analyzes machine sensor readings, failure records, error logs, and maintenance history to identify unusual machine behaviour and predict potential component failures.

The system is designed to support predictive maintenance, evidence-based root-cause analysis, and what-if analysis under different operating conditions.

*Objectives*

Analyze machine operating conditions and maintenance history.

Detect unusual machine behaviour using machine learning.

Predict potential component failures.

Investigate few-shot learning for limited-data scenarios.

Identify probable failure causes using historical evidence.

Explore what-if analysis, downtime prediction, and maintenance alerts.

*Dataset*

The project uses the Microsoft Azure Predictive Maintenance dataset, which includes:

Machine telemetry: voltage, rotation, pressure, and vibration.

Machine error records.

Component failure records.

Maintenance and component replacement records.

Machine metadata, including model and age.

Dataset source: https://www.kaggle.com/datasets/arnabbiswas1/microsoft-azure-predictive-maintenance
